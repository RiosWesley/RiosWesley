# 🏗️ Como penso sobre software

```ts
const engenharia = {
  primeiro: "entender o problema",

  depois: [
    "entender o sistema",
    "mapear restrições",
    "planejar",
    "implementar",
    "testar",
    "revisar",
    "entregar",
  ],

  principios: {
    complexidade: "precisa ser justificada",
    arquitetura: "deve resolver problemas reais",
    ia: "é multiplicador, não substituto de julgamento",
    codigo: "precisa sobreviver ao mundo real",
  },
};
```

### Algumas regras que tento carregar comigo

> 🧠 **Entender antes de implementar.**
> Código costuma ser a parte fácil. Descobrir qual código deveria existir é o trabalho de verdade.

> ⚖️ **Complexidade precisa ser conquistada.**
> Nem todo problema precisa de uma arquitetura digna de uma empresa com 40 milhões de usuários.

> 🤖 **IA é uma ferramenta de engenharia.**
> O valor não está apenas em gerar código, mas em construir processos melhores para entender, implementar e validar sistemas.

> 🚀 **Software existe para ser usado.**
> Uma solução simples em produção vale mais que uma arquitetura perfeita vivendo eternamente em um diagrama.
